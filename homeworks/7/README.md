# Описание

Программа получает требования из `requirements/login.md`, создаёт четыре промпта и отправляет их в Ollama. Модель генерирует тест-кейсы, чек-лист, тест-план и QA-отчёт. Затем модель сама оценивает каждый промпт и результат по четырём критериям: читаемость, контекстность, чёткость целей и покрытие сценариев.

## Запуск

Нужны Python 3 и уже работающая Ollama с загруженным образом в Docker с доступом к `http://localhost:11434`.

Запустить программу из папки проекта:

```
python main.py
```

Сторонние библиотеки Python не нужны.

## Результаты

В папке `output/` появятся:

- `*.prompt.md` — четыре промпта;
- `test_case.md`, `checklist.md`, `test_plan.md`, `qa_report.md` — четыре документа;
- `evaluation.md` — оценки модели с обоснованиями по четырём критериям для каждого документа.
