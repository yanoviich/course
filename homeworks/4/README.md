## Запуск Ollama в Docker

```
docker run -d --name ollama -p 11434:11434 ollama/ollama
```

## Загрузить модель:
```
docker exec -it ollama ollama pull llama3.2:3b
```

## Установка зависимостей
```
pip install -r requirements.txt
```

## Генерация датасета
```
python generate_dataset.py
```

После запуска в папке `dataset` появятся 10 файлов `doc_01.txt` - `doc_10.txt`.

## Запуск RAG
```
python rag.py
```

Пример вопроса:
```
Что такое регрессионное тестирование?
```

Пример вопроса вне базы знаний:
```
Как приготовить борщ?
```

Для такого вопроса подходящие документы не должны быть найдены, и программа вернет сообщение о том, что в локальной базе знаний нет подходящей информации.
