## Требования

Docker с Docker Compose, Python 3 и доступ в интернет для первой загрузки модели.

## Запуск

Из папки проекта:

```sh
sh start.sh
python -m pip install -r requirements.txt
python -m pytest -v -s
```

`start.sh` запускает Ollama в Docker и загружает модель `llama3.1:8b`. Тесты отправляют запросы в `http://localhost:11434/api/chat`. Для другого адреса установите переменную `OLLAMA_URL`.

Остановка: `docker compose down`. Модель сохраняется в томе Docker.

## Проверки

1. **Логичность:** 10 разных задач, процент точных совпадений с эталонами.
2. **Повторяемость:** один вопрос 10 раз. Отдельно выводятся доля наиболее частого ответа и доля правильных ответов.
3. **Устойчивость:** 10 вариантов написания одного вопроса, процент правильных ответов.
4. **Известные факты:** 3 вопроса с эталонными ответами.
5. **Отсутствие выдуманных данных:** 2 вопроса, на которые нет ответа в предоставленном тексте.
6. **OpenAPI-манифест:** 3 запроса по `api_manifest.json`; метод сравнивается без учёта регистра. Отсутствующая операция должна давать `null` для метода и пути.

Проверки качества выводят проценты **без порога**. `PASSED` у них означает, что измерение выполнено, а не что модель дала 100% правильных ответов. Ошибки HTTP и отсутствие ответа модели обрабатываются внутри функции отправки запросов. Для коротких ответов используется строгое сравнение после удаления лишних пробелов, внешней пунктуации и различий регистра;
