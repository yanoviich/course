Ты старший QA инженер по автоматизации.

Тебе необходимо сгенерировать 3 контракт автотеста на Python 3 с использованием Pytest и библиотеки
Requests для API который располагается по адресу - "https://jsonplaceholder.typicode.com"

Требования:
Для понимания взаимодействия с API используй описание расположенное на странице - "https://jsonplaceholder.typicode.com/guide"
Используй простые конструкции языка при реализации автотестов
Необходимо чтобы тесты затронули только коды ответов: 200, 400 и 404

Дополнительные условия:
Не выдумаывай дополнительную локику
Необходимо вывести только код который легко запустится через командную строку
Используй современные практики для написания контрактного тестирования
НЕ добавляй комментарии в код (или сведи их к минимуму).
НЕ добавляй пояснения, Markdown-форматирование (включая "python") или какой-либо дополнительный текст за пределами кода.
Выведи ТОЛЬКО чистый Python-код, готовый для копирования и запуска с помощью pytest.
Убедись в правильных отступах и синтаксисе
