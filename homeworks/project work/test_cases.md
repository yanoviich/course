**Тест-кейсы для формы регистрации на сайте OTUS.ru**

### ID: TC-01. Проверка обязательных полей

#### Название: Проверка обязательных полей

#### Предусловия:

* Открыта главная страница сайта OTUS.ru
* Нажата кнопка "Зарегистрироваться"

#### Шаги:

1. Оставить поле "Имя" пустым
2. Оставить поле "Фамилия" пустым
3. Ввести в поле "Электронная почта" адрес в правильном формате
4. Нажать кнопку "Зарегистрироваться"

#### Ожидаемый результат:

* В полях "Имя" и "Фамилия" отображается красная рамка и красный значок с восклицательным знаком
* В поле "Электронная почта" отображается зеленая рамка и зеленый значок с галочкой
* Внизу страницы отображается сообщение "Заполните поле"

### ID: TC-02. Проверка поля "Имя"

#### Название: Проверка поля "Имя"

#### Предусловия:

* Открыта форма регистрации
* В поле "Имя" ввести значение длиной более 32 символов

#### Шаги:

1. Ввести в поле "Имя" значение длиной более 32 символов
2. Нажать кнопку "Зарегистрироваться"

#### Ожидаемый результат:

* В поле "Имя" отображается красная рамка и красный значок с восклицательным знаком
* Внизу страницы отображается сообщение "Убедитесь, что это значение содержит не более 32 символов (сейчас [количество])"

### ID: TC-05. Проверка согласия на обработку персональных данных

#### Название: Проверка согласия на обработку персональных данных

#### Предусловия:

* Открыта форма регистрации
* Не выбрано согласие на обработку персональных данных

#### Шаги:

1. Нажать кнопку "Зарегистрироваться"

#### Ожидаемый результат:

* Поле согласия на обработку персональных данных выделяется красным цветом

### ID: TC-06. Проверка регистрации через VK

#### Название: Проверка регистрации через VK

#### Предусловия:

* Открыта форма регистрации
* Нажата кнопка "Зарегистрироваться через VK"

#### Шаги:

1. Нажать кнопку "Зарегистрироваться через VK"

#### Ожидаемый результат:

* Открывается страница авторизации в VK
* После успешной авторизации происходит безшовный переход в личный кабинет

### ID: TC-07. Проверка закрытия формы

#### Название: Проверка закрытия формы

#### Предусловия:

* Открыта форма регистрации

#### Шаги:

1. Нажать на значок крестика в верхней части страницы

#### Ожидаемый результат:

* Форма регистрации закрывается

### ID: TC-08. Проверка перехода в личный кабинет

#### Название: Проверка перехода в личный кабинет

#### Предусловия:

* Успешно зарегистрированный пользователь

#### Шаги:

1. Нажать на кнопку "Зарегистрироваться"

#### Ожидаемый результат:

* Происходит безшовный переход в личный кабинет
* Имя пользователя отображается в блоке профиля пользователя в верхней части сайта
