# Обучение модели на данных

## Запуск

1. Запустите Ollama и скачайте модель: `ollama pull llama3.1:8b`.
2. Установите зависимости: `python -m pip install -r requirements.txt`.
3. Запустите: `python main.py`.

Ollama должна быть доступна по адресу `http://localhost:11434`.

Программа собирает 100 разных чисел от 0 до 9999 для обучения и ещё 100 других для проверки. Неверные метки и повторы отбрасываются; при нехватке данных запрос повторяется до 10 раз. Результаты сохраняются в `ollama_train.json` и `ollama_test.json`.

Числа переводятся в 14 двоичных цифр. Нейросеть `MLPClassifier` обучается методом `fit()` на этих цифрах и метках, затем `predict()` определяет чётность новых чисел. В коде нет формулы сравнения чётности и нет вручную заданного правила по последней цифре. Двоичное представление облегчает обучение, но не гарантирует заданную точность.
